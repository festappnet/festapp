Pro automatické načítání plateb z Fio připravte API token pro čtení účtu a propojte ho se správným bankovním účtem pořadatele.

Co potřebujete předem

Oprávnění k účtu ve Fio Internetbankingu a právo upravit bankovní účet pořadatele v naší aplikaci. Ověřte, že jde o tentýž skutečný účet. Vytvoření tokenu v bance, jeho autorizace a uložení v aplikaci jsou tři různé kroky.

Vytvořte a autorizujte token u Fio

  1. Otevřete Fio Internetbanking

    Přihlaste se na ib.fio.cz a vyberte správný účet.

  2. Přejděte do Nastavení → API

    Vytvořte token s oprávněním pouze sledovat účet. Pro načítání příchozích transakcí nepotřebujete právo zadávat platební příkazy. Zkontrolujte jeho dobu platnosti.

  3. Dokončete autorizaci

    Potvrďte vytvoření způsobem požadovaným bankou. Pouhé vyplnění formuláře token neaktivuje. Při více podepisujících osobách dokončete všechna požadovaná potvrzení.

  4. Vyčkejte na aktivaci

    Fio uvádí dostupnost API pět minut po úspěšné autorizaci. Podrobnosti jsou v oficiální dokumentaci Fio API.

Vložte token v nastavení bankovního účtu

V administraci pořadatele otevřete Bankovní účty, vyberte odpovídající Fio účet a otevřete Propojení s bankou. Do pole FIO API Token vložte token, nastavte jeho skutečnou platnost a použijte Aktualizovat token. Po uložení aplikace zobrazuje pouze maskovanou informaci; celý token znovu nezpřístupňuje.

Rozlišujte uložení tokenu a fungující načítání

Zkontrolujte stav propojení, případné hlášení a údaj Poslední úspěšné načtení přes FIO API. Úspěšné uložení tokenu samo ještě nedokládá úspěšné načtení z banky. Je-li token uložený a čeká na autorizaci či ověření, nejdříve dokončete autorizaci a vyčkejte na aktivaci. Nevytvářejte při každém čekání nový token.

Chyba nesprávného nebo neaktivního tokenu vyžaduje kontrolu tokenu a autorizace. Nesoulad účtu znamená, že token patří k jinému účtu. Výpadek spojení nebo dočasná chyba se nerovnají neplatnému tokenu. Pokud je synchronizace pozastavená, zkontrolujte přepínač automatické synchronizace.

Když objednávka pořád není zaplacená

Ověřte účet, částku a variabilní symbol přijaté platby a její přiřazení k objednávce. Přijatá transakce, její přiřazení a stav objednávky jsou samostatné údaje. Zákazníka nežádejte o druhou platbu bez ověření první.
