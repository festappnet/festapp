Na automatické načítavanie platieb z Fio pripravte API token na čítanie účtu a prepojte ho so správnym bankovým účtom organizátora.

Čo potrebujete vopred

Oprávnenie k účtu vo Fio Internetbankingu a oprávnenie upraviť bankový účet organizátora v aplikácii. Overte, či ide o ten istý skutočný účet. Token v banke vytvoríte, autorizujete a potom uložíte v aplikácii.

Postup vo Fio Internetbankingu

Najprv vytvorte a autorizujte token v bankovníctve. Potom ho uložte v nastaveniach účtu organizátora podľa postupu nižšie.

Vytvorte a autorizujte token vo Fio

  1. Otvorte Fio Internetbanking

    Prihláste sa na ib.fio.cz a vyberte správny účet.

  2. Prejdite cez Nastavenia do časti API

    Vytvorte token len na sledovanie účtu. Na načítavanie prichádzajúcich transakcií nemusíte povoliť zadávanie platobných príkazov. Skontrolujte platnosť tokenu.

  3. Dokončite autorizáciu

    Potvrďte vytvorenie spôsobom, ktorý vyžaduje banka. Po vyplnení formulára je ešte potrebné token aktivovať. Ak podpisuje viac osôb, dokončite všetky požadované potvrdenia.

  4. Počkajte na aktiváciu

    Fio uvádza dostupnosť API päť minút po úspešnej autorizácii. Podrobnosti nájdete v oficiálnej dokumentácii Fio API.

Vložte token v nastaveniach bankového účtu

V administrácii organizátora otvorte Bankové účty, vyberte príslušný účet Fio a otvorte Prepojenie s bankou. Do poľa FIO API Token vložte token a nastavte jeho skutočnú platnosť. Potom token aktualizujte. Po uložení aplikácia zobrazuje iba maskovaný údaj.

Overte, či sa platby načítavajú

Skontrolujte stav prepojenia, prípadné hlásenie a údaj o poslednom úspešnom načítaní cez Fio API. Aj po úspešnom uložení musí načítanie prebehnúť samostatne. Ak token čaká na autorizáciu alebo overenie, najprv dokončite autorizáciu a počkajte na aktiváciu.

Pri chybe nesprávneho alebo neaktívneho tokenu skontrolujte token aj autorizáciu. Nesúlad účtu znamená, že token patrí k inému účtu. Výpadok spojenia alebo dočasná chyba môžu nastať aj s platným tokenom. Ak je synchronizácia pozastavená, skontrolujte prepínač automatickej synchronizácie.

Keď objednávka stále nie je zaplatená

V detaile objednávky na karte Platby overte účet, sumu, variabilný symbol a priradenie prijatej transakcie. Prijatá transakcia, jej priradenie a stav objednávky sú samostatné údaje.
