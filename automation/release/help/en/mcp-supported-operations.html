Check what your connection permits

First ask the agent to discover accessible events and available tools. Each task depends on the implemented operation, registered client permissions, approved consent and your current account rights. A prompt cannot expand access. Additional permissions require a fresh sign-in and consent.

The public ChatGPT connection uses an order summary profile: it withholds contacts, notes and registration answers and does not permit changes. An operator connection with the required permissions offers additional tools. Some areas, such as the program and speakers, apply only to events using those features.

How this documentation stays current

The catalog uses the same registry as the MCP server, input schemas, shared permission contract and public ChatGPT client policy. Permission labels reuse consent-screen translations. Help builds reject a stale snapshot after those sources change until it is regenerated.

Prompt wording is editorial. Examples reference existing operations and their references are checked during the build. This avoids maintaining a separate manual capability list.

For automated processing, use the MCP JSON catalog with input schemas. This describes the implementation rather than proving deployment or access to every tool. Verify the available tools after signing in.
