Set clear ticket variants, prices and availability. Your limits must match what you can actually sell.

Before you begin

You need a form and permission to edit its offer. Prepare variant names, prices, currencies and quantities. Decide which variants share the same physical capacity.

Prepare products and prices

  1. Open the form offer

    A product type groups related choices, such as admission or dinner. A product is one priced choice, such as standard admission or a vegetarian dinner.{{APP_LINK:products}}

  2. Add the choices

    Use Add Product Type and Add Product. Enter a clear name, price and currency. A zero price means a free option, not zero availability.

  3. Check selection rules

    Choose whether selection is required and whether multiple choices are allowed. Enable Show only for options you want to offer. Check any preselected choice.

{{MEDIA:en/forms/editor}}

Set the available quantity

Set a quantity or capacity for limited products. Where the field explicitly says that zero means unlimited, do not use zero to close sales; use visibility or availability instead. Do not apply this rule to a standing area's seat count.

When different price variants consume the same stock, put them in the same capacity group. Two separate limits of 100 do not create one shared limit of 100. For assigned seating, also check each seat's product binding.

Changes during sales

Save price or availability changes and check the public form. Changing the offer does not automatically rewrite existing order prices. Open the existing order detail, choose Tickets and places and edit the item. Recheck the balance. Use scheduled price changes only when a change is intended for a specific future time. For an existing purchase, follow changing an order.{{APP_LINK:orders}}

Verify the result

Check every visible option, currency and total in a private window. Availability can depend on the sales period, shared capacity and current holds. Check existing reservations before increasing limits to resolve an unavailable option. Check the sales period and availability in Forms.{{APP_LINK:forms}}

Discount codes

A discount code lets buyers save on tickets at checkout. For example, DANCE10 reduces a €50 ticket to €45.

  1. Turn on Discount codes for the event

    In Event settings, find Discount codes in the Features section. Turn on the switch on the Discount codes card, then select Save in the bottom bar. Enable the feature for each event where you want to accept codes. It is off by default.{{APP_LINK:settings}}

    {{MEDIA:en/discount-codes/settings}}

  2. Create a code in Products

    Open Products, select Discount codes, then Create code. Use 4 to 32 ASCII letters, digits or hyphens. Letter case is ignored. Once someone uses the code, its name is locked.{{APP_LINK:products}}

    {{MEDIA:en/discount-codes/list}}

  3. Set the discount and choose where it applies

    For a Percentage discount (%), enter 10 for ten percent. For a Fixed discount, enter the amount and currency. It is deducted once per order from the total of eligible items, and the order must use the same currency. Expand Forms and Products to narrow the scope. An empty selection includes all applicable forms or products in the event. The discount uses current prices, including scheduled price changes.

  4. Set validity and usage, then activate the code

    Use Valid from and Valid until to set the optional start and end in the event’s local time. The code expires at the chosen end time. The Order limit counts created orders, including orders awaiting payment. Ticket quantity has no effect on usage. Leave it empty for unlimited use. New codes start inactive. Turn on Active and select Save.

    {{MEDIA:en/discount-codes/editor}}

  5. Try the code before sharing it

    Open the public order form in a private window, select an eligible ticket and apply the code. Compare the original price, discount and discounted total on the review screen. You can stop at the review screen. A use is counted once an order is created.

    {{MEDIA:en/discount-codes/checkout-review}}

Check usage and pause a code

With permission to view orders, you can see the number of uses and the total discount granted per currency. To pause a code, open it, turn off Active and save. Turning off the event feature pauses all codes in the event. Existing discounts and uses stay in the history. Turning the feature back on leaves the accumulated usage in place.

Why a code may fail

Check that the feature is enabled, the code is active and within its validity dates, there are uses left, and the form and selected product match its scope. For a fixed discount, also check the order currency. Buyers can enter one code per order before confirming the purchase.

The discount excludes platform fees and informational surcharges. If an item has a real deposit, its discounted price must stay above that deposit. A zero-price order without a deposit requires no payment.

Waiting list customers enter the code when accepting an offer. Each separate partial acceptance creates a new order and requires entering the code again. Preprinted ticket batches cannot use codes.

How a discount affects order changes

Discounted orders support corrections to contact information and nonfinancial answers, ticket delivery, cancellation and eligible refunds. Product, price, event date and seat changes are blocked. Cancellation, expiry and refunds do not restore uses. Refunds are based on the amount paid. The original discount remains visible in the order overview after cancellation.
