Check guests in using the mobile app: verify the event, look up or scan a ticket, then confirm its use. This guide describes the scanner in the phone app.

Prepare the phone and access

  1. Get access for the correct event

    The organizer prepares scanning access in ticket administration. Share the scanning code only with check-in staff; it is different from a customer's ticket QR.{{APP_LINK:tickets}}

  2. Open the scanner in the mobile app

    If prompted, enter the scanning code supplied by the organizer. Check the event name at the top. Allow camera access, connect to the internet and charge the phone.

  3. Try check-in before doors open

    Test a sample QR code and lighting on a physical phone. Check access for each staff member. If manual ticket search is enabled for the event, the magnifying-glass Search button appears at the bottom right.

Find a ticket manually

Tap the magnifying glass, enter a name, email or ticket symbol in the search field and select the matching ticket. Search is a fallback when enabled for the event. A ticket symbol is different from the symbol of the whole order.

{{MEDIA:en/native-scanner/search}}

Scan and confirm a ticket

Point the camera at the ticket QR or select the ticket through search. Check the name, symbol and state. A valid ticket has a green background and a confirmation button. Reading the ticket alone does not confirm admission.

{{MEDIA:en/native-scanner/valid}}

Tap the ticket confirmation button when admitting the guest. After saving succeeds, the state changes to Used with the time of use and the background turns blue. Check this result before admitting the next guest.

{{MEDIA:en/native-scanner/confirmed}}

Used or unpaid tickets

Checking a previously used ticket shows Used and the earlier time. The confirmation button is no longer offered. Resolve the situation with the responsible organizer.

{{MEDIA:en/native-scanner/used}}

An Ordered ticket appears on an orange background. This does not confirm payment. The app still offers ticket confirmation in this state, so verify payment and the organizer's admission rules first. Confirming use does not record a payment.

{{MEDIA:en/native-scanner/unpaid}}

Camera or connection problems

If the camera cannot start, check camera permission in the phone settings and retry using the camera button. Use the magnifying glass if search is available. If internet access drops, restore the connection or use another connected device. Do not treat admission as confirmed until the app shows the saved use.

After check-in

Handle payment and delivery issues through orders. Used-ticket counts do not represent the number of people currently inside the venue.
