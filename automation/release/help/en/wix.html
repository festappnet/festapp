Install vstupenky.online from the Wix App Market to display your public ticket form on your website. Manage orders, tickets and payments in vstupenky.online.

Prepare your public form

Save your event form and copy its public link, such as https://vstupenky.online/form/YOUR-FORM. Use your actual link without query parameters or a fragment. Open it separately to check the event and confirm sales are open.{{APP_LINK:forms}}

Install the Wix app

  1. Select your website

    Open vstupenky.online in the Wix App Market, click Add to Site, select your website and follow the installation prompts.

  2. Place the widget

    Open the page in your Wix editor. Find vstupenky.online under App Widgets or installed apps in the add-elements menu. Menu names vary by editor. Adjust the widget position and width, including the mobile layout.

Save the form link and title

Select the widget and open Settings. In the Czech settings panel, paste your public link into Odkaz formuláře and enter an accessible title in Přístupný název formuláře. Set Přizpůsobit vzhled webu (Match website appearance). It defaults to on and applies only to this widget; off keeps the form’s own appearance. Click Uložit nastavení, wait for confirmation, then reopen the panel to check the saved values. Configure each widget separately. No HTML code or API key is required.

Publish and check the page

The editor and Preview show a placeholder. Save and publish your website, then open its public address. Check readability, mobile width and the order summary. Use a dedicated test event for seat selection or order submission, as these actions can reserve actual tickets.

If the form does not appear

  • Missing widget: check the app is installed on the correct Wix website.
  • Placeholder: open the published page instead of the editor or Preview.
  • Invalid link or missing form: use an existing public form link, rather than an administration URL. Replace YOUR-FORM with your actual form.
  • Changes are missing: confirm the settings were saved and publish the website again.
  • Poor text contrast: turn off Přizpůsobit vzhled webu in this widget’s Settings, save and publish the website again. Also check the standalone link; set the form’s own colors and font in its appearance settings.

If the issue continues, open the form link separately and follow troubleshooting. Include your Wix page address, browser and a description when contacting support.

Orders and service fees

Manage purchases in vstupenky.online orders. Orders are not transferred to Wix Events or the Wix cart. The widget has no separate subscription; ticket service fees follow your organizer agreement.

The appearance control is part of the updated widget. If it is missing or cannot be saved, the app needs an update and its Wix registration must support the property; saving the form in vstupenky.online is not enough. Wix uses nested frames, so only the accessible appearance around the widget can be inherited, not necessarily that of the full website. The seating plan keeps its own appearance. Always check the published page.
