Use the vstupenky.online module to add ticket sales to Joomla. Install the ZIP, paste your public form link and display the module in an article or a template position.

Prepare the form and download the module

  1. Prepare an event and a public order form in vstupenky.online. Copy its saved public link. Your organizer account is separate from your Joomla account.{{APP_LINK:forms}}
  2. Download vstupenky.online.zip using the download button in the official Joomla Extensions Directory listing. Do not extract the ZIP.
  3. Sign in to Joomla with permission to install extensions and edit modules and articles. The module supports Joomla 5 and 6; the screenshots show Joomla 6.

The module is free to download. The external service has its own commercial terms and pricing agreed with the organizer.

Install the ZIP in Joomla

  1. Open System. Under Install, select Extensions.
  2. On the upload tab, select vstupenky.online.zip or drag it onto the upload area.
  3. Wait for the successful module installation message.
{{MEDIA:en/joomla/01-install}}

Create and configure a module

  1. Open Content → Site Modules → New and select vstupenky.online. If a module already exists, open it from the list instead.
  2. Enter a title such as Ticket sales. In Saved public form URL, paste your saved https://vstupenky.online/form/YOUR-FORM link without ?embed=1, other query parameters or a fragment.
  3. Enter a descriptive Accessible iframe title, such as Tickets for our ball, for screen reader users.
  4. Keep Automatic height and Use website appearance enabled. The initial height can remain 800 pixels.
  5. Set the status to Published and access to Public. You can hide the module title.
{{MEDIA:en/joomla/02-module}}

Display the form inside an article

  1. Set a custom module position, such as ticket-article. Type it into the position selector and confirm. Use a position your template does not render to avoid displaying the form twice.
  2. Under Menu Assignment, allow the required pages. The simplest choice is all pages; the custom position means the form appears where you insert it into an article.
  3. Save and close the module. Note its ID in the module list.
  4. Under System → Manage → Plugins, check that Content - Load Modules is enabled.
  5. Open or create an article and insert {loadmoduleid 123} on its own line. Replace 123 with your module's actual ID. No HTML embed code or iframe is needed.
  6. Publish the article with public access and make it accessible, for example through a menu item. Save and open the public page.

Alternative: a template position

To display the module outside article content, choose a real template position and select the pages under Menu Assignment. Do not insert {loadmoduleid …} into the article for this option. Available positions and widths depend on your template; choose a wide area for a seating plan.

Check the published result

  • Open the public page while signed out, and on a mobile screen. The form should appear once and fit the available content width.
  • Check the event name, ticket options and form height. If the event has assigned seats, check that the seating plan opens and closes. Only make test reservations or orders on your own test event.
  • Try Open the form in a new tab below the form. Visitors can use this link if their browser blocks embedded content.

If the form does not appear

  • The article displays {loadmoduleid …} as text: enable Content - Load Modules and check the module ID.
  • The article is empty: check publication, public access and menu assignment for both the article and module. A custom position alone does not display anything; add the module code to the article.
  • The form appears twice: use an unused custom position for an article embed.
  • The URL cannot be saved: use the saved public https://vstupenky.online/form/ link, without query parameters or a fragment, rather than an administration URL.
  • The form is clipped or blocked: clear website and optimization plugin caches. Ask your administrator to check external content restrictions, or follow the embed troubleshooting guide.

Management and updates

Manage tickets, capacity, orders and payments in vstupenky.online. Joomla stores the public link and presentation settings without your service password or API key. Changes to the form appear when the page reloads. Update the module URL if you change the saved public link. Module updates use Joomla's regular extension update system.
