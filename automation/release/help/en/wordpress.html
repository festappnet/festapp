You can embed your public order form with a Custom HTML block. Copy the example code below and replace the form links.

Before you begin

Save your public form first. You need permission to save iframe and script markup. Copy the saved public link from Forms, then return to WordPress. If needed, create and open the form for sales first.{{APP_LINK:forms}}

Code to embed in WordPress

Copy the entire code. In both links, replace YOUR-FORM with the part after /form/ in your saved public form link. This example uses automatic height and inherits your website’s appearance.

<div data-festapp-embed-host>
  <iframe data-festapp-embed data-festapp-style="inherit"
    src="https://vstupenky.online/form/YOUR-FORM?embed=1"
    title="Order form" allow="clipboard-write"
    width="100%" height="800" style="border:0;max-width:100%"
    loading="lazy"></iframe>
  <p><a href="https://vstupenky.online/form/YOUR-FORM"
    target="_blank" rel="noopener noreferrer">Open the form in a new tab</a></p>
</div>
<script src="https://vstupenky.online/embed.js" defer></script>

Use WordPress without a plugin

In the WordPress editor, add a Custom HTML block and paste the entire code. In newer WordPress versions, select the block and choose Edit code, then keep the HTML tab selected. Confirm your changes, save and check the published page. Your WordPress role or security settings may remove scripts; use fixed height when necessary.

What updates automatically?

The embedded form is served by the ticket service, so its current content and runtime load from there. Save changes to the block URL, height or inherited style with the WordPress page. For a missing or clipped form, use troubleshooting.
