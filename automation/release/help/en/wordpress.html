Embed your public order form with the plugin’s native block or a Custom HTML block. Each embed can have its own appearance setting.

Before you begin

Save your public form first. Copy the saved public link from Forms, then return to WordPress. If needed, create and open the form for sales first.{{APP_LINK:forms}}

Install the official plugin

Open Plugins > Add New Plugin, search for vstupenky.online by festappnet, then install and activate it. It is also available in the official WordPress.org directory. Update an existing installation to 1.0.4 or later for the appearance control. Open Settings > vstupenky.online or choose Get started in the plugin list. The plugin is free; the external organizer service has its own pricing and terms. No WooCommerce or API key is required.

With the updated plugin, add the vstupenky.online block. Enter the saved public form link and set Match website appearance. It defaults to on and applies only to this block; turning it off keeps the form’s own appearance. It is independent of automatic or fixed height. Save and publish the page, and refresh website caches if needed.

This appearance choice applies only to this embed and does not change the saved form settings. Anyone with the public link can choose the appearance of their own embed; this grants no access to event, price or payment administration. The saved form appearance is a default, not a lock on other websites.

For a shortcode, use inherit_style="false" to disable inheritance, for example [vstupenky_online url="https://vstupenky.online/form/YOUR-FORM" inherit_style="false"]. If the block has no appearance control, it needs the updated plugin package; saving the form does not add controls to an older installation. The Custom HTML instructions below are a separate alternative.

Code to embed in WordPress

Copy the entire code. In both links, replace YOUR-FORM with the part after /form/ in your saved public form link. This example uses automatic height and matches your website appearance. To keep the form’s own appearance, use the generator with Match website appearance unchecked.

<div data-festapp-embed-host>
  <iframe data-festapp-embed data-festapp-style="inherit"
    src="https://vstupenky.online/form/YOUR-FORM?embed=1"
    title="Order form" allow="clipboard-write"
    width="100%" height="800" style="border:0;max-width:100%"
    loading="lazy"></iframe>
  <p><a href="https://vstupenky.online/form/YOUR-FORM"
    target="_blank" rel="noopener noreferrer">Open the form in a new tab</a></p>
</div>
<script src="https://vstupenky.online/embed.js" defer></script>

Use WordPress without a plugin

In the WordPress editor, add a Custom HTML block and paste the entire code. In newer WordPress versions, select the block and choose Edit code, then keep the HTML tab selected. Confirm your changes, save and check the published page. Your WordPress role or security settings may remove scripts; use fixed height when necessary. Website appearance cannot be inherited without the helper script.

What updates automatically?

The embedded form is served by the ticket service, so its current content and runtime load from there. Save changes to the block URL or height with the WordPress page. To change Match website appearance, generate new code, replace the HTML in this block and publish the page again. This choice belongs to that embed, not to the saved form. For a missing or clipped form, use troubleshooting.
