Embed your public order form with the plugin’s native block or a Custom HTML block. All embeds use the saved form appearance choice.

Before you begin

Save your public form first. Copy the saved public link from Forms, then return to WordPress. If needed, create and open the form for sales first.{{APP_LINK:forms}}

Install the official plugin

Open Plugins > Add New Plugin and search for vstupenky.online by festappnet. Install and activate it, or update an existing installation to 1.0.5 or later. You can also find it in the official WordPress.org directory. The plugin is free; the external service has its own organizer pricing and terms. No WooCommerce or API key is required.

Add the vstupenky.online block to your page. Enter the saved public form URL, choose an accessible title and automatic or fixed height, then save and publish the page. The editor shows local controls; the actual form appears on the published page.

Set Match website appearance in the form’s Design and save the form. All embeds apply the saved choice on their next load, without replacing HTML or changing plugin settings. The seating plan keeps its own appearance.

A shortcode is also available: [vstupenky_online url="https://vstupenky.online/form/YOUR-FORM"]. Replace YOUR-FORM with your saved form slug. It uses the same saved appearance setting as the block.

Code to embed in WordPress

Copy the entire code. In both links, replace YOUR-FORM with the part after /form/ in your saved public form link. This example uses automatic height and the saved form appearance setting. To keep the form’s own appearance, disable Match website appearance in the form’s Design settings and save the form.

<div data-festapp-embed-host>
  <iframe data-festapp-embed
    src="https://vstupenky.online/form/YOUR-FORM?embed=1"
    title="Order form" allow="clipboard-write"
    width="100%" height="800" style="border:0;max-width:100%"
    loading="lazy"></iframe>
  <p><a href="https://vstupenky.online/form/YOUR-FORM"
    target="_blank" rel="noopener noreferrer">Open the form in a new tab</a></p>
</div>
<script src="https://vstupenky.online/embed.js" defer></script>

Use WordPress without a plugin

In the WordPress editor, add a Custom HTML block and paste the entire code. In newer WordPress versions, select the block and choose Edit code, then keep the HTML tab selected. Confirm your changes, save and check the published page. Your WordPress role or security settings may remove scripts; use fixed height when necessary. Website appearance cannot be inherited without the helper script.

What updates automatically?

One saved form setting in vstupenky.online controls every embed. Open the form’s Design, set Match website appearance and save the form. Enabled uses the available host font, background and colors; disabled keeps the form appearance. HTML, WordPress, Joomla and Wix apply the saved choice on subsequent page loads without replacing embed code. The seating plan keeps its own appearance. An active checkout is not restarted.
