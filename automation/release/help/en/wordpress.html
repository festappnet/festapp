You can embed your public order form with the WordPress plugin or a Custom HTML block.

Before you begin

Save your public form first. You need permission to install plugins for the plugin option, or permission to save iframe and script markup for the HTML option. Copy the saved public link from Forms, then return to WordPress. If needed, create and open the form for sales first.{{APP_LINK:forms}}

Use the plugin

The Czech vstupenky.online plugin version 1.0.0 has been submitted to the WordPress.org directory and is awaiting manual review. It is not yet available through directory search.

  1. Upload the reviewed ZIP

    Download vstupenky.online 1.0.0. In WordPress, open Plugins → Add New Plugin → Upload Plugin, select the ZIP, install it and activate it.

    {{MEDIA:en/wordpress/01-get-started}}

  2. Add the ticket form block

    Open your page editor and add the vstupenky.online block. Paste the saved public form link and choose the height mode.

    {{MEDIA:en/wordpress/02-block-editor}}

  3. Publish and check

    Check the published page and the order summary on desktop and mobile.

The shortcode alternative is [vstupenky_online url="{{FORM_ORIGIN}}/form/your-form"].

Use WordPress without a plugin

Open the HTML generator, copy the code and paste it into a Custom HTML block. In newer WordPress versions, select the block and choose Edit code, then keep the HTML tab selected. Confirm your changes, save and check the published page. Your WordPress role or security settings may remove scripts; use fixed height when necessary.

{{MEDIA:en/wordpress/03-custom-html}}

What updates automatically?

The embedded form is served by the ticket service, so its current content and runtime load from there. Save changes to the block URL, height or inherited style with the WordPress page. New block functionality and plugin fixes arrive as plugin updates. For a missing or clipped form, use troubleshooting.
