You can embed your public order form with a Custom HTML block.

Before you begin

Save your public form first. You need permission to save iframe and script markup. Copy the saved public link from Forms, then return to WordPress. If needed, create and open the form for sales first.{{APP_LINK:forms}}

Use WordPress without a plugin

Open the HTML generator, copy the code and paste it into a Custom HTML block. In newer WordPress versions, select the block and choose Edit code, then keep the HTML tab selected. Confirm your changes, save and check the published page. Your WordPress role or security settings may remove scripts; use fixed height when necessary.

{{MEDIA:en/wordpress/03-custom-html}}

What updates automatically?

The embedded form is served by the ticket service, so its current content and runtime load from there. Save changes to the block URL, height or inherited style with the WordPress page. For a missing or clipped form, use troubleshooting.
