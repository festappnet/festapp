Show your public ticket form directly in your website. Changes to the saved form are reflected in the embedded version.

What you need

A saved public form and permission to insert custom HTML on your website. Some website builders require a paid plan. If custom HTML is unavailable, use a button linking to the standalone form.

Prepare your HTML code

In the administration, open your saved form through Forms → Settings → Embed on your website, or paste its public link into the generator below. The generator prepares code; it does not create an order or reserve tickets. Copy the saved public link from your event's Forms.{{APP_LINK:forms}}

Insert the code in your website

  1. Add a custom HTML block

    Open the page in your website editor and add a block that accepts HTML. For platform steps, follow WordPress or Webnode. Wix has a separate App Market installation guide; Joomla has a module installation guide.

  2. Paste the complete code

    Keep the iframe, fallback link and helper script together in both height modes. Save and publish the page.

  3. Check the published page

    Editors may show only a placeholder. Check the actual published page on desktop and mobile. Continue to the order summary to verify that a longer form stays visible.

Automatic or fixed height

Automatic height uses the helper script to adjust to the form content. Fixed height keeps a set frame height; the helper script still supplies website appearance. If your website removes scripts, use fixed height and check that visitors can reach every field and the submit button. Website appearance cannot be inherited without the script.

Match your website

In Embed on your website or the generator above, choose Match website appearance before copying the code. Enable it to use the host website’s font, background and colors, or disable it to keep the form appearance. This choice applies only to this embed and works with either height mode when the website allows the helper script. You do not need to save the form. To change an existing embed, copy the new code, replace the old HTML on your website and publish the page again. The seating plan keeps its own appearance.

Use a direct link instead

Add a button labelled Buy tickets and set its link to the public form URL.
