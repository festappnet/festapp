Show your public ticket form directly in your website. Changes to the saved form are reflected in the embedded version.

What you need

A saved public form and permission to insert custom HTML on your website. Some website builders require a paid plan. If custom HTML is unavailable, use a button linking to the standalone form.

Prepare your HTML code

Paste the public form link. The generator prepares code; it does not create an order or reserve tickets. Copy the saved public link from your event's Forms.{{APP_LINK:forms}}

Insert the code in your website

  1. Add a custom HTML block

    Open the page in your website editor and add a block that accepts HTML. For platform steps, follow WordPress or Webnode.

  2. Paste the complete code

    Keep the iframe, fallback link and, for automatic height, the helper script together. Save the page.

  3. Check the published page

    Editors may show only a placeholder. Check the actual published page on desktop and mobile. Continue to the order summary to verify that a longer form stays visible.

Automatic or fixed height

Automatic height uses the helper script to adjust to the form content. If your website removes scripts, choose fixed height and check that visitors can reach every field and the submit button.

Match your website

By default, the form uses your website’s font, background and colors. Turn off Match website appearance to use the form’s own appearance. The seating map keeps its own appearance.

Use a direct link instead

Add a button labelled Buy tickets and set its link to the public form URL.

Where orders and payments go

Orders remain in our application. Use the order guide to find a purchase, and payment settings to check the receiving account and instructions.{{APP_LINK:orders}}
