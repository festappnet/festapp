Connect your AI assistant to vstupenky.online through MCP, choose its event access and check the tools available to your connection.

Shortest version: paste this into your agent

Connect to https://mcp.vstupenky.online/mcp and show my events.

This is enough when the connection is already configured. First-time setup needs a client supporting remote MCP and OAuth, client configuration and your sign-in. Enter your password only on the vstupenky.online sign-in page, never in the chat. The address vstupenky.online.mcp is not this service. Opening the MCP URL in a browser does not connect your agent.

Let Codex configure the connection

If your agent can use the terminal and configure Codex, give it this setup prompt:

Set up Codex MCP “vstupenky”: https://mcp.vstupenky.online/mcp, OAuth client festapp-codex, scopes offline_access, festapp:ticket-layouts:read and festapp:forms:read. Leave sign-in to me.

Choose a connection for your task

  • Forms in Codex: use the registered festapp-codex client below. Reading and editing require separate permissions. Verify the actual tools after signing in.
  • Order summaries in ChatGPT: the public festapp-chatgpt client supports summary reads. It does not grant form editing or return buyer contacts and registration answers.
  • Other clients: require Streamable HTTP, OAuth and a registered client ID with their own callback. Automatic client registration is disabled. Do not assume the Codex registration works in another application.

Step by step in Codex

  1. Add the server

    Run this in a terminal with a current Codex CLI. If a connection named vstupenky already exists, check its URL and client before adding it again.

    codex mcp add vstupenky --url https://mcp.vstupenky.online/mcp --oauth-client-id festapp-codex

    If you configured this connection using the older guide, remove oauth_resource from this MCP server’s Codex configuration and sign in again. Codex discovers the resource automatically; do not add --oauth-resource.

    This is a public client ID; no client secret is needed. Update Codex if these OAuth options are unavailable.

  2. Sign in to read forms

    codex mcp login vstupenky --scopes offline_access,festapp:ticket-layouts:read,festapp:forms:read

    The offline_access scope allows the connection to refresh after the short-lived token expires. If the connection reports invalid_scope after a few minutes, run this command again and approve the new consent. Existing consent is not expanded automatically.

    Complete sign-in in the browser, select one event and review the requested permissions. Selecting an entire organizer may include its future events; start with a single event.

  3. Check the actual connection

    Start a new conversation or refresh tools, then ask:

    Use MCP vstupenky to list Linden Hall Ball forms and inspect the one I choose.

    Replace the sample event with your own. Success requires actual tool responses, the correct event and a returned form. Look for festapp_access_inspect, festapp_forms_list and festapp_forms_inspect. An assistant saying it is connected is insufficient.

  4. Enable editing when needed

    Sign in again with form editing permission:

    codex mcp login vstupenky --scopes offline_access,festapp:ticket-layouts:read,festapp:forms:read,festapp:forms:write,festapp:occasion-settings:read

    Review the new consent. Existing consent never gains permissions automatically. Editing needs festapp_forms_save and your current account's form editing rights. If the scope is rejected or the tool is missing, follow the troubleshooting section.

Connect in ChatGPT

  1. On ChatGPT web, open Plugins, select + and Add custom MCP server. Account and workspace policies apply.
  2. Enter vstupenky.online, server URL https://mcp.vstupenky.online/mcp, and OAuth. Use the registered public client festapp-chatgpt, without a secret.
  3. Order summaries require both festapp:ticket-layouts:read and festapp:orders:read. If the interface cannot configure the provided client or both scopes, ask your integration administrator for the prepared connection. The URL alone may be insufficient.
  4. Complete sign-in and event consent, install the connection and select it with @ in a conversation. Ask for available events and tools first.

This public connection reads sales summaries, order states and amounts. Use Codex for forms. A public directory listing is not required to configure a custom MCP connection.

Troubleshooting

  • Unknown client or callback: check the client ID and application. Codex uses the registered loopback callback http://127.0.0.1/callback; ChatGPT has its own registered callback. Registration changes require the integration administrator.
  • Missing form or save tools: check requested permissions, renewed consent, event selection, current account rights and discovered tools. Public ChatGPT does not permit form editing. A prompt cannot add permission.
  • Missing event: check your account and consent selection. Resolve duplicate names using date and organizer.
  • Expired sign-in or MFA required: reconnect. If the client cannot complete verification, contact support; do not disable MFA.
  • A concurrent edit: reload the current form and approve a new proposal. If a response is lost, the agent must retry the identical command and identifier to avoid duplicate changes.

Revoke access

Open MCP connection management, sign in and revoke the connection. Then remove it in your AI application. Removing it from a conversation alone does not revoke service consent.
