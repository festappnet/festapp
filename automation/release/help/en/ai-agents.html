Connect your AI assistant to vstupenky.online through MCP, choose its event access and check the tools available to your connection.

Shortest version: paste this into your agent

Connect to https://mcp.vstupenky.online/mcp and show my events.

This is enough when the connection is already configured. First-time setup needs a client supporting remote MCP and OAuth, client configuration and your sign-in. Enter your password only on the vstupenky.online sign-in page, never in the chat. The address vstupenky.online.mcp is not this service. Opening the MCP URL in a browser does not connect your agent.

Let your agent configure the connection

If your agent can configure MCP connections in your AI application, give it this prompt:

Set up an MCP connection named “vstupenky” to https://mcp.vstupenky.online/mcp using OAuth. Use the client registration intended for this application and request offline_access, festapp:ticket-layouts:read and festapp:forms:read if the registration supports them. If registration or permissions are missing, tell me what to request from the integration administrator. Leave sign-in and access approval to me. Then list my available events.

Connection requirements

Your AI application must support remote MCP over Streamable HTTP and OAuth authentication. It needs a registered client ID with a callback matching that application. Automatic client registration is disabled. Ask your integration administrator for connection details; do not reuse another application's registration.

Available tasks depend on the client registration, granted permissions, selected events and your current account rights. A connection for order summaries may not support reading or editing forms.

Connect your application

  1. Add the MCP server

    In your AI application's connection or integration settings, add https://mcp.vstupenky.online/mcp and select OAuth. Enter the registered client ID intended for that application. Public clients do not require a client secret. If the connection already exists, check its settings.

  2. Sign in and choose access

    For reading forms, request festapp:ticket-layouts:read and festapp:forms:read if supported by the registration. Request offline_access to refresh the connection after the short-lived token expires. Order summaries require festapp:ticket-layouts:read and festapp:orders:read.

    Complete sign-in in the opened window, select one event and review the requested permissions. Selecting an entire organizer may include its future events; start with a single event.

  3. Check the actual connection

    Refresh available tools or start a new conversation, then ask your agent to list available events. For a connection with form access, ask:

    Use MCP vstupenky to list Linden Hall Ball forms and inspect the one I choose.

    Replace the sample event with your own. Success requires actual tool responses, the correct event and a returned form. Look for festapp_access_inspect, festapp_forms_list and festapp_forms_inspect. An assistant saying it is connected is insufficient.

  4. Enable editing when needed

    If the registration supports form editing, add festapp:forms:write in the connection settings. Also add festapp:occasion-settings:read to read the sales schedule. Sign in again and approve the new consent. Existing consent does not gain permissions automatically.

    Editing requires festapp_forms_save and your current account's form editing rights. If the scope is rejected or the tool is missing, follow the troubleshooting section.

Troubleshooting

  • Unknown client or callback: check the client ID and application. The callback must match the registration for the application you are using. Registration changes require the integration administrator.
  • Missing form or save tools: check requested permissions, renewed consent, event selection, current account rights and discovered tools. A registration limited to order summaries does not permit form editing. A prompt cannot add permission.
  • Missing event: check your account and consent selection. Resolve duplicate names using date and organizer.
  • Expired sign-in or MFA required: reconnect. If the client cannot complete verification, contact support; do not disable MFA.
  • A concurrent edit: reload the current form and approve a new proposal. If a response is lost, the agent must retry the identical command and identifier to avoid duplicate changes.

Revoke access

Open MCP connection management, sign in and revoke the connection. Then remove it in your AI application. Removing it from a conversation alone does not revoke service consent.
