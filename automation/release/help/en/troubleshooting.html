Start with the saved public form link, then check the published website.

The form does not load

Open its public URL separately. It must contain /form/ and the saved form identifier. Do not use an administration address. Check the sales period and form availability. Check sales availability and ticket capacity in administration.{{APP_LINK:forms}}

Content or the submit button is cut off

For automatic height, keep the complete code, including the helper script. Check whether your website removed it. If scripts are unsupported, choose fixed height and check the longer order summary on mobile. Prepare fresh code in the HTML generator and compare height modes.

The colors or font look wrong

Disable Match website appearance in the form appearance settings, save the form and reload the page. Check light and dark backgrounds, including prices, totals and form controls. See embedded form appearance.

An older version is showing

Save both the form and the website page. Clear your website or WordPress cache, then check the published page in a private browser window.

The buyer did not receive an email or tickets

Open order detail → Emails. Check the recipient and Delivery details, then repair the address or explicitly request sending from that tab. Saving changes alone does not send a message.

Contact support

Send the published page URL, the public form URL, a screenshot and the steps that reproduce the problem. Include your website builder and height setting. Do not send passwords, access tokens or buyers' personal details. Contact support.

Received transfer but unpaid order

Ask the bank administrator to follow the unmatched payment guide. Check the original transfer and receiving account before requesting another payment.

Central form appearance

One saved form setting in Festapp Tickets controls every embed. Open the form’s Design, set Match website appearance and save the form. Enabled uses the available host font, background and colors; disabled keeps the form appearance. Embeds apply the saved choice on subsequent page loads without replacing embed code. The seating plan keeps its own appearance. An active checkout is not restarted.
