# Documentation archive

This directory contains completed plans, superseded setup guides and point-in-time
audit evidence. These
files are retained for traceability and may describe old versions, temporary
worktrees or superseded rollout procedures.

Superseded bank receiving guides are retained in `setup/` with links back to
the current BankSync and outbound SES guides.

Do not execute an archived prompt as a current runbook. Use
[the documentation map](../README.md), current runbooks and open work items
instead.
