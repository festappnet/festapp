# Festapp Tickets - English landing concept

English global landing concept for `tickets.festapp.net`, based on the approved rough-print design at commit `5629de3a1`. Open `index.html` directly from disk. No server is required.

Preserves the original concert, blue ink illustration style, layout and ticket check-in scene. The classic ballroom and English sample ticket are generated edits of the original artwork. All interface and example text is English. This preview uses one selected visual direction without comparison controls or a language switch.

This is an offline design concept, not a deployment. External event, terms and privacy links target the proposed domain; those routes and domain configuration have not been verified. The owner confirmed info@festapp.net as the contact email. The existing booking link is retained. The rejected ticket/F draft has been removed. The landing consumes the canonical global SVG/header and favicon from `assets/brand/festapp-tickets/`. Historical brand inputs are retained outside this deliverable in `docs/design/festapp-global-brand-research-2026-11-11/`. The sample QR retains its original synthetic identifier and is not a live ticket.

The customer-facing global page uses Festapp Tickets and info@festapp.net. Its sole regional-brand mention is the footer link “Czech version”. Regional artwork and research files are not included in this preview or the global logo ZIP.
