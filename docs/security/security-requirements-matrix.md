Stav 2026-10-16: lokální implementace, celý bezpečnostní program není uzavřený. Referenční verze je OWASP ASVS 5.0.0, rozsah jsou níže uvedené aplikační scénáře podle autoritativního plánu, API Security 2023 API4/API6 a DoS Cheat Sheet.
