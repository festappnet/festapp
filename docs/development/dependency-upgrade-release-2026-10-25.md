# Dependency upgrade release integration - 2026-10-25

The release is integrated in an isolated checkout of current canonical main.
Unrelated dirty workspaces are preserved. The authorized production target is
vstupenky.online / prod/festapptickets only.

Flutter 3.47.7 / Dart 3.13.5, standalone Material/Cupertino UI, timezone 0.11.2,
cross_file 0.4, desktop_drop 0.9.2 and the coordinated current picker packages
are included. Existing MapLibre DPR/style-image/JNI/lifecycle/renderer patches
are preserved on MapLibre 0.3.7. Every source copy has a FESTAPP_PATCH.md.

Current main already owns venue_seat_picker 0.3.7 and venue_layout_core 0.2.2
under vendor/blueprint. This release qualifies wrapper 0.4.0 and the npm compiler artifact 0.3.7
from current canonical editor main, then imports their real archives together
with the host. It does not replace them with the older local sibling checkout.
The redundant tracked pubspec_overrides.yaml is removed; pubspec.yaml alone
selects the versioned package paths. There are no absolute dependency paths.

The new canonical blueprint editor's picker and graphics imports use ImportFile
and retain provider bytes before returning a selected file. Existing object,
resource, kernel and editor contracts remain on current main. Existing main's
six-digit login exchange and context invalidation are preserved.

The full timezone dataset retains historical IANA aliases. Core and app tests
initialize through OccasionTimeContext instead of replacing that dataset with
the smaller upstream default. Time policies are unchanged: UTC instants versus
wall time, saved zones/settings, Prague fallback, 04:00 program boundaries,
overnight grouping, device-local notification labels and DST gaps/overlaps.

The initial local-upgrade receipts under /tmp/festapp-clean-2026-10-25 predate
integration with newer main and do not qualify this release. Current integration
receipts are under /tmp/festapp-upgrade-release-20261025. Fresh client/editor
verification and tenant build/deploy receipts are recorded there.

Direct test/build tooling remains constrained below its newest release: stable
Flutter pins test_api 0.7.12, which keeps test at 1.31.1 and build_runner at
2.16.1. No forced SDK override is used.

Previously shipped host-only gallery, clipped palette and CSS-pixel hit allowance
fixes now live in the canonical editor source and its qualified distributions.
The host pnpm patch is removed. Widget-level clipping coverage belongs to the
package instead of importing its private internals from an app test.
